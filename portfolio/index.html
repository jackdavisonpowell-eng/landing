01 · what is autogod

AUTOGOD

AUTOGOD is an autonomous agent system I run on self-hosted LLM inference — repurposed data-center GPUs doing the work cloud APIs would otherwise bill me for. It watches for useful work, plans it, does it, and hands the result back. Autogod has been through and will go through many iterations, he works 24/7 to improve himself, leaving zero idle GPU hours. This dashboard, the showcase page, and the fleet control panel are all part of the same project.

Everything on the showcase page was built this way — free to run, with no usage limits, because it's my own hardware. Autogod has come a long way, originally i had a single p100 running qwen3 14b, now I have dual p100's and a 32gb v100, and now i run qwen3.8 27b q4 abliterated imatrix models.

02 · how I got here

Self-taught, hardware first

I built my first PC at 11 and have been building systems — for myself, then for family and friends — ever since. No formal CS background; learns by doing, ships things that actually run instead of studying the theory first.

The newer territory is server administration and AI infrastructure — local LLMs, RAG, embeddings, agent orchestration — learned the same way: by struggling through it myself instead of taking a course.
