What AUTOGOD is

01

AUTOGOD is an autonomous agent system I run on self-hosted LLM inference — repurposed data-center GPUs doing the work cloud APIs would otherwise bill me for. It watches for useful work, plans it, does it, and hands the result back. AUTOGOD has been through and will go through many iterations; he works 24/7 to improve himself, leaving zero idle GPU hours. This site, the showcase page, and the fleet control panel are all part of the same project.

Everything on the showcase page was built this way — free to run, with no usage limits, because it's my own hardware.

09

Three cards, and the BIOS that would not allow it

Adding a third card to a Gigabyte X99 board is not a slot problem, it is an address-space problem. Three compute cards need their memory mapped above the 4 GB line, and on that board the stock F22 firmware's Above 4G Decoding toggle is broken — switch it on and the machine will not boot.

The fix was a modded BIOS from the Win-Raid community that raises the high MMIO window from 256 GB to 1 TB. Flashing it meant building a FreeDOS stick and using a patched flash tool, because the stock one refuses a modified image outright. The board has two BIOS chips and the backup one is the safety net, so that chip does not get touched — a bad flash then just fails to POST a few times and the board restores itself.

Then the settings that actually matter: Above 4G on, PCIe forced to Gen 3 rather than Auto because the third card will not train otherwise, and the legacy compatibility layer off. My first attempt black-screened on exactly that last point and needed the CMOS cleared. Once it came up, the 32 GB V100 went in beside the pair of P100s.

They all run at PCIe 3.0 x8, because the CPU only has 28 lanes to hand out. That is the real ceiling on this board, and it is why the cards talk to each other through the host bridge instead of directly.

A fleet, not a box

FRIDAY, the voice assistant, takes the V100. AUTOGOD, the worker, takes the P100 pair. Which model sits on which card is swapped from a panel on the wall, so the whole rig re-lays-out itself depending on whether I am talking to it or it is working for me.

How I learn

03

The newer territory is server administration and AI infrastructure — local LLMs, RAG, embeddings, agent orchestration — learned the same way as the hardware was: by struggling through it myself instead of taking a course.

That has a cost and I know it. It also means every part of this stack is something I can open up and fix at two in the morning, because there is no layer of it I did not put there.
