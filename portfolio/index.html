What AUTOGOD is

01

An autonomous agent system running on self-hosted inference — repurposed data-center GPUs doing the work cloud APIs would otherwise bill me for.

  • Watches for useful work, plans it, builds it, hands back the result
  • Runs 24/7 and rates its own output, leaving zero idle GPU hours
  • This site, the showcase and the fleet control panel are all part of it
  • Everything on the showcase is free to run with no usage limits, because the hardware is mine
the rack — every machine in one place

15

Three cards, and the BIOS that would not allow it

Fitting a third compute card was an address-space problem, not a slot problem.

  • Stock firmware’s Above 4G Decoding toggle is broken on that board
  • Flashed a modded BIOS raising high MMIO from 256 GB to 1 TB
  • FreeDOS stick and a patched flasher, since the stock tool rejects modified images
  • Above 4G on, PCIe forced to Gen 3, legacy video off, one cleared CMOS
  • All three run at x8 — the CPU has only 28 lanes to give

How I learn

The newer territory is server administration and AI infrastructure — local LLMs, RAG, embeddings, agent orchestration — learned the same way as the hardware was: by struggling through it myself instead of taking a course.

That has a cost and I know it. It also means every part of this stack is something I can open up and fix at two in the morning, because there is no layer of it I did not put there.
