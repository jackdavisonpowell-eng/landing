# Shot list

Drop files in here with these exact names and they appear on the site. No code
change, no rebuild. A name that is not here yet simply does not paint, and the
hatched plate underneath shows through — that is a designed state, so the page
never looks broken while you are still shooting.

Every photo is forced to hard monochrome in CSS, so lighting and camera do not
have to match between shots. Shoot for shape and contrast, not colour.
