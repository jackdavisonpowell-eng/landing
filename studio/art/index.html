  ▐     ▀▀
        This one lives entirely in the terminal: a voice-driven assistant for
        Windows and Linux, wired into your actual life — mail, calendar, tasks,
        notes, and a memory that survives a reboot.

        Say "hey marvin" or hit the hotkey, talk, and he answers out loud in
        about a second and a half. Interrupt him mid-sentence and he stops and
        listens. He can look at your screen, open your apps, drive the media
        keys and run a shell command when you ask for one.

        The brain is a 35B mixture-of-experts model split across twin Tesla
        P100s — datacentre cards from 2016, bought secondhand. A third card, a
        GTX 1660 SUPER, only posts in that board because the BIOS was modded to
        allow it; it carries the wake word and the embeddings. The whole rig
        runs Debian and answers from anywhere over Tailscale.

        No cloud. No subscription. No key leaving the building — every token is
        generated on hardware sitting in this room.

        Built by an 18 year old in a cave, out of a box of spare parts.

   ▄██▀▀▀ Install Notes ─── ─  ─
        LINUX
          1.  git clone the jarvis-stack repo, then  python3 -m venv venv
          2.  venv/bin/pip install -r requirements.txt
          3.  set HOST in agent.py to the box running the model
          4.  ./autogod           wake word + voice
              ./autogod --text    typed, no microphone needed

        WINDOWS
          1.  winget install Python.Python.3.12
          2.  run setup-windows.ps1  (builds the venv, pulls the wake models)
          3.  autogod              Page Down is push-to-talk

        Both clients need line of sight to the model host — same LAN, or on
        the tailnet. Nothing else is required; there are no API keys to set.
